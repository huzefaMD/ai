# Lesson 3 : `Brainstorming & Ideation`

## Mode 1- Quantity Mode
### Best for: Breaking creative blocks, early stage exploration
```
<task>
Generate 20 ideas for [topic].
No filtering - quantity over quality.
Even wild or unusual ideas are welcome.
I'll filter afterwards.
</task>

<context>
[Your situation]
</context>

<dont>
Don't explain each idea -
just list them fast.
</dont>
```
## Real Example:
```
<task>
Generate 20 content ideas for HuzefAI's
LinkedIn page this month.
No filtering - quantity over quality.
Mix of formats: posts, polls,
carousels, stories, articles.
</task>

<context>
HuzefAI teaches Cloud, DevOps, AI
to IT professionals and freshers in Chennai.
Goal: Build authority and generate leads.
</context>
```
## Mode 2- Quality Mode
### Best for: When you need fewer but fully developed ideas
```
<task>
Give me 5 ideas for [topic].
For each idea provide:
1. The core concept
2. Why it would work
3. How to execute it
4. Potential challenges
5. First step to start today
</task>
```
## Real Example:
```
<task>
Give me 5 ideas for HuzefAI to generate
passive income alongside our live courses.

For each idea:
1. What it is
2. Revenue potential per month
3. Time to build
4. How it fits with our existing courses
5. First step to start this week
</task>
```
## Mode 3-Constraint Mode

### Best for: Real-world brainstorming with actual limitations
```
<task>
Generate ideas for [topic] with
these specific constraints:

Budget: [amount]
Time: [timeframe]
Team size: [just me / small team]
Technical skill: [level]
</task>
```
## Real Example:
```
<task>
Generate 10 marketing ideas for HuzefAI
with these constraints:

Budget: ₹0 - completely free only
Time: Maximum 1 hour per day
Team: Just Huzefa - no employees yet
Goal: Get 20 new students in 30 days

Only ideas that realistically work
within these constraints.
</task>
```
## Mode 4 - Opposite Mode
### This is a hidden gem technique. Start with deliberately BAD ideas, then flip them.
```
<task>
First give me 10 terrible ideas for
[topic] - ideas that would definitely fail.

Then for each bad idea, flip it into
a good idea by reversing or improving
the core concept.
</task>
```
## Real Example:
```
<task>
First give me 10 terrible ideas for
marketing HuzefAI - ideas guaranteed to fail.

Then flip each one into a good idea
by reversing the core concept.
</task>
```
## Mode 5-Perspective Mode
### Best for: Understanding how different people see your idea
```
<task>
Evaluate [idea] from these
different perspectives:

1. As a potential student (fresher)
2. As a potential student (experienced IT pro)
3. As a competitor watching HuzefAI
4. As an investor evaluating HuzefAI
5. As a skeptic who thinks it won't work

For each perspective give:
- Their first reaction
- Their biggest concern
- What would convince them
</task>
```

## PART 4: Problem Solving
Turn Claude into your problem-solving partner for real HuzefAI challenges.

### The Problem Solving Framework
```
<role>
Expert problem solver and business
strategist with experience in EdTech.
</role>

<problem>
[Describe your problem clearly]
</problem>

<context>
[Relevant background information]
</context>

<task>
Solve this problem using this framework:

1. DIAGNOSE
What is the real root cause?

2. REFRAME
Look at this problem from 3
completely different angles.

3. GENERATE OPTIONS
Give 5 possible solutions -
ranging from conservative to bold.

4. EVALUATE
For each solution: pros, cons,
effort, risk, speed.

5. RECOMMEND
Best solution for my situation
with specific first steps.
</task>
```

## PART 5: Creative Thinking Frameworks
These are classic business thinking frameworks - Claude applies them instantly to YOUR
situation.

### Framework 1 - SCAMPER

(Substitute, Combine, Adapt, Modify, Put to other use, Eliminate, Reverse)
```
<task>
Apply the SCAMPER framework to
HuzefAI's current AWS course:

S - Substitute: What could we replace?
C - Combine: What could we combine it with?
A - Adapt: What could we adapt from elsewhere?
M - Modify: What could we modify or magnify?
P - Put to other use: New audience or use case?
E - Eliminate: What could we remove?
R - Reverse: What if we reversed the format?

Generate 2-3 ideas for each letter.
</task>
```
### Framework 2 - First Principles
```
<task>
Apply first principles thinking to
HuzefAI's business model.

1. Break down our current model into
its most basic assumptions
2. Question each assumption -
why do we do it this way?
3. Rebuild from scratch - if we were
starting today with no constraints,
how would we design HuzefAI?
4. What's one radical idea this produces?
</task>
```
### Framework 3- Blue Ocean Strategy
```
<task>
Apply Blue Ocean Strategy to HuzefAI.

ELIMINATE: What do competitors do that
we should completely remove?

REDUCE: What do competitors emphasize
that we should reduce?

RAISE: What should we raise well above
the industry standard?

CREATE: What should we create that
nobody in this space offers?

Result: What's HuzefAI's Blue Ocean -
our unique uncontested market space?
</task>
```
### Framework 4 - The 5 Whys
```
<task>
Apply the 5 Whys to this problem:

Problem: HuzefAI is not growing as
fast as I want.

Why 1: Why is growth slow?
Why 2: Why does that cause slow growth?
Why 3: Why does that happen?
Why 4: Why does that occur?
Why 5: Why is that the case?

At each level dig deeper into the
REAL root cause - not the surface symptom.
End with the true root cause and
one focused solution.
</task>
```
## When to Use Which Mode

Stuck for ideas?
> Quantity Mode - generate 20 fast

Need a fully developed plan?
> Quality Mode - 5 ideas in depth

Working with real constraints?
Constraint Mode - budget/time/team

Feeling uncreative?
> Opposite Mode - start with bad ideas

Making an important decision?
> Perspective Mode - see all viewpoints

Content planning?
> Content Idea Machine

Business growth?
> Revenue Stream or Partnership Ideation

Stuck on a problem?
> Problem Solving Framework

Need fresh thinking?
> SCAMPER, First Principles, Blue Ocean
